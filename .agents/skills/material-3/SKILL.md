## Consume, never copy

- Values: `packages/design/tokens/` (`tokens.css` `--md-sys-*`, `tokens.json`, `tokens.rs`, `tokens.zig`, `ansi.json`), generated by Material Color Utilities from `assets/brand/brand.toml`. A value from the specs is not pasted into code: it is used to check or fix the generator (`packages/design/src/build.ts`).
- Targets, libraries, Figma, Stitch: skill `ui-system`. Rust: crate `aphrody-ui` (M3 contracts).

## Key rules

1. Color: semantic roles only; text and icons in the container's `on-*` (`m3.color.on-pairs`); `*-container` never for text; surface hierarchy via `surface-container-*` (surface-tint obsolete); `outline` for interactive borders, `outline-variant` for dividers.
2. Themes: light and dark, each in standard, medium and high contrast (`m3.color.three-contrast-levels`).
3. Type: the 15 styles of the scale (display/headline/title/body/label × L/M/S), rem units, text resizable to 200 %.
4. Shape: radius scale none → full; elevation: levels 0 to 5 only, shadow only when needed.
5. States: state layer in the content color, opacities hover 0.08, focus 0.10, pressed 0.10, dragged 0.16; disabled 0.38; focus ring 3dp, offset 2dp, `secondary`.
6. Motion: springs (expressive scheme by default, standard for utilitarian UI); spatial for geometry, effects for color/opacity; easing + duration as fallback; reduced motion respected.
7. Layout: classes compact < 600, medium 600–839, expanded 840–1199, large 1200–1599, extra-large ≥ 1600dp; margins 16dp (compact) then 24dp; 8dp grid with 4dp sub-units.
8. Accessibility: target ≥ 48 × 48dp, contrast 4.5:1 text / 3:1 large text and non-text, accessible name for every icon control, logical focus order, focus returned to the opener, mirrored RTL.
9. Components: take the variant and measurements from `components/material-3.json`; on the web, the implementation is `@material/web` via `@aphrody/design/components` (ui-system), not an in-house component.

## Verify before asserting

- Token values: `gh api repos/material-components/material-web/contents/tokens/versions/latest/sass` (Apache-2.0); springs: `androidx/androidx` `compose/material3/.../tokens/*MotionTokens.kt`; contrast: `packages/google-design/upstream/material-color-utilities`.
- Usage rules: reread the m3 page cited in `source` (SPA: `agent-browser open <url>` then `agent-browser read`, ~1 request/s).
- Gap between spec and `packages/design`: fix the generator, regenerate, `bun test --cwd packages/design`.

General Google Design principles: skill `google-design`.
