## Channel / version policy

- Source of truth: `third_party/chrome-channels.toml`, regenerated by `scripts/chrome-channels.sh` (factory runs it on every non-build step). Never hardcode versions.
- Snapshot 2026-11-12: stable `157.0.8103.78` (V8 15.7.112.43), beta `158.0.8127.18`, dev `159.0.8144.0`; ToT checkout = 160.
- Factory builds the Stable tag by default (`refs/tags/<ver>`). ChromiumOS follows Stable milestone: branch `release-R<m>-*.B` (fallback `stable`).
- Toml also pins clang, rust, v8/skia/angle/dawn/pdfium/boringssl/devtools/harfbuzz/freetype/catapult revisions per channel.

## Checkout / sync (docs/linux/build_instructions.md)

```sh
git clone https://chromium.googlesource.com/chromium/tools/depot_tools.git; export PATH="$HOME/depot_tools:$PATH"
mkdir ~/chromium && cd ~/chromium && fetch --nohooks chromium      # factory adds --no-history
cd src && ./build/install-build-deps.sh && gclient runhooks
# pin to a release tag (factory pattern)
git fetch --depth 1 origin "refs/tags/$ver:refs/tags/$ver" && git checkout "$ver"
gclient sync -D --force --nohooks --no-history --with_tags && gclient runhooks
# PGO profiles (needed for chrome_pgo_phase=2): .gclient custom_vars {"checkout_pgo_profiles": True}
```

ToT update: `git rebase-update && gclient sync`.

## Configure / build

```sh
gn gen out/Default                   # args live in out/Default/args.gn; `gn args out/Default` edits
gn args out/Default --list --short   # verify every arg name on the synced tag
autoninja -C out/Default chrome      # or headless_shell, unit_tests, browser_tests
gn refs out/Default --testonly=true --type=executable --all <file.cc>   # which test binary
out/Default/unit_tests --gtest_filter="Suite.*"
```

- Siso: `use_siso` (build/toolchain/siso.gni, default `use_siso_default`); remote exec `use_remoteexec` (build/toolchain/rbe.gni, default false). Non-Google REAPI: `SISO_CREDENTIAL_HELPER`, `RBE_service_no_security=true` or mTLS `RBE_tls_client_auth_{key,cert}`, own `backend.star`. Tips: `docs/siso_tips.md`.
- Rust: `docs/rust/README.md` (`rust_static_library`, `//third_party/rust`, `third_party/rust/README-importing-new-crates.md`), `docs/rust/ffi.md`, `clippy.md`, `unsafe.md`, `using_cargo.md`.
- Testing: `docs/testing/`. Sandbox: `docs/design/sandbox.md`, `docs/linux/sandbox_ipc.md`, `docs/linux/suid_sandbox_development.md`.

## headless_shell

- Args (`headless/headless.gni` declare_args, defaults): `headless_use_embedded_resources=false`, `headless_enable_commands=true` (--screenshot/--print-to-pdf/--dump-dom), `headless_use_prefs=true`.
- Incompatible: `headless_enable_commands` + `headless_use_embedded_resources` -> assert at `headless/BUILD.gn:22`.
- Upstream preset `build/args/headless.gn` (`import("//build/args/headless.gn")`): ozone_platform="headless", embedded resources ON, commands OFF, prefs OFF, `use_bundled_fontconfig=true`, `icu_use_data_file=false`, `v8_use_external_startup_data=false`, alsa/bluez/cups/dbus/gio/kerberos/libpci/pulseaudio/udev/glib/gtk/qt5/qt6/pangocairo/mold off, `rtc_use_pipewire=false`.
- Run: `headless_shell --remote-debugging-port=9222 <url>`; Chrome itself: `chrome --headless` (old headless removed from chrome binary, headless/README.md; standalone headless_shell binaries published since M118).

## ChromiumOS

chromiumos/docs `developer_guide.md` is a stub -> https://www.chromium.org/chromium-os/developer-library/guides/development/developer-guide/

```sh
repo init -u https://chromium.googlesource.com/chromiumos/manifest -b stable   # or release-R<m>-<n>.B
repo sync -j4                       # factory: -c --no-tags --no-clone-bundle --optimized-fetch, --depth=1 on init
cros query boards; BOARD=amd64-generic
cros build-packages --board=$BOARD                                  # current upstream, run outside chroot
cros build-image --board=$BOARD --no-enable-rootfs-verification test
cros flash usb:// $BOARD/latest
```

Legacy form in `cros-factory.sh`: `cros_sdk --nouse-image -- setup_board|build_packages|build_image --board=$BOARD [--noenable_rootfs_verification test]`. Image: `src/build/images/$BOARD/latest/chromiumos_test_image.bin`. TODO: migrate factory to `cros build-packages/build-image`.
