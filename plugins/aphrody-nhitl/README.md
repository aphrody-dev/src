# aphrody-nhitl

No human in the loop for Claude Code, through supported extension points only (plugin hooks,
user settings, headless CLI). claude.exe is never patched.

| Piece                         | File                               | Behavior                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| :---------------------------- | :--------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PreToolUse, PermissionRequest | `src/hook.ts` + `src/policy.ts`    | Allow every call (PermissionRequest `allow` also covers `-p` runs and critical-path `rm`), except in plan mode. Deny: `git push --force`/`+refspec`/`--mirror`/deleting main, history rewrite (`filter-branch`, `filter-repo`, `rebase --root`, `reflog expire`, `update-ref`); deleting, or overwriting an existing non-empty file (`>`, `truncate`, `Set-Content`, `Out-File`, `cp`/`mv` destination), outside `C:\src`, `C:\msys`, temp (or a root itself) unless git holds a clean tracked copy; printing secret files (`/etc/aphrody/secrets.env`, `.env*` except examples, DPAPI `Protect`/`Credentials`/`Vault`, `ProtectedData::Unprotect`, `.credentials.json`, `.git-credentials`, private SSH keys); publishing Epic/Unreal or MSVC SDK/CRT content (`git push` outgoing files, `gh release`, `rclone`, `scp`, `rsync`, `npm/bun/cargo publish`...); `AskUserQuestion` (decide alone). Shell code is re-checked through `bash -c`, `pwsh -Command`/`-EncodedCommand`, `cmd /c`, `eval`/`iex`, heredocs fed to a shell, `ssh host cmd`. Grep content searches over a directory get a `!{.env,...}` glob (ripgrep reads hidden files). Git probes share a 15 s budget (spent = deny); a policy exception denies shell commands only. |
| Notification                  | `src/hook.ts`                      | Async, log only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Stop, SubagentStop            | `src/hook.ts`                      | `decision: "block"` while a goal (`--goal` of the launcher) or TodoWrite items stay open, unless the last message names a blocker, background tasks are running, or `NHITL_MAX_CONTINUE` (default 3) consecutive continuations were used (reset when `stop_hook_active` is false). `NHITL_DONE` in the reply closes the goal. Claude Code's own 8-in-a-row cap still applies.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| SubagentStart/Stop            | `src/hook.ts`                      | Running-agent registry in `~/.claude/state/nhitl/agents-all.json`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| SessionStart                  | `src/hook.ts`, `src/learn-auto.ts` | Local digest (busy sessions, running agents, goal, open todos on resume, learn journal, nhitl denies in 24 h), no network, about 45 ms wall. Detached `/learn` at most once per 24 h.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Stop, SessionEnd              | `src/learn-capture.ts`             | Lesson capture to `~/.claude/learning/journal.jsonl` (moved from `~/.claude/hooks`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Status line                   | `src/statusline.ts`                | `nhitl · mode · model · agents n[/total] · ctx %`, wired in `~/.claude/settings.json`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Launcher                      | `bin/claude-nhitl.ts`              | `claude -p` with `--permission-mode bypassPermissions --permission-prompts none --output-format stream-json --verbose`, `--session-id`/`--resume`/`--continue`, stream teed to `~/.claude/learning/runs/<sid>.jsonl`. Shebang `bun --no-env-file`; entries bun loaded from a `.env` are not passed to claude. As root, claude runs via `runuser -u $NHITL_RUN_AS` (default `agent`), never with `IS_SANDBOX`. `--help` for the runner contract.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

Decisions: `~/.claude/learning/nhitl.jsonl` (commands redacted, allows carry no command text).
Tests: `bun test ./test` here (`bun test plugins/aphrody-nhitl` from the root). Install: `claude plugin marketplace add C:/src/plugins` then
`claude plugin install aphrody-nhitl@aphrody --scope user`; after edits bump `version` and run
`claude plugin marketplace update aphrody && claude plugin update aphrody-nhitl@aphrody`.
