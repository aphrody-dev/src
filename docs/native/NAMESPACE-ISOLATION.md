## 2. Hard Invariants Enforced Automatedly

1. **Zero `src/` Subdirectory Overlap**:
   - `C:\src\src\` contains strictly `{arch, drivers, include, kernel, nt, ui, wasm, wayland, wine, Makefile, DEPS.rules, .clang-format}`.
   - `third_party/bun/src/` (`136` crates/dirs: `aot`, `ast`, `bundler`, `bun_core`, `cli`, `css`, `http`, `install`, `jsc`, `js_parser`, `runtime`, `sql`, `uws`, `wyhash`, `yarr`, `zstd`, ...) has **0 directory collisions** with `C:\src\src\`.
   - `systemd` (`basic/`, `libsystemd/`, `journal/`, `udev/`, `units/`) is never merged into `C:\src\src\`; fleet service definitions live exclusively under `infra/fleet/**/systemd/aphrody-*.{service,timer}`.
   - `wine` (`dlls/`, `programs/`, `loader/`, `server/`) and `reactos` (`ntoskrnl/`, `win32ss/`, `hal/`, `subsystems/`) stay isolated in `third_party/wine` and `apps/nt`, exposing only clean protocol/status primitives in `src/wine/` and `src/nt/`.
2. **Zero Package / Crate Name Collision**:
   - Cargo: `bun_*` (Bun) vs `aphrody-*` / `depot-*` / `lore-*` / `tv-*` (Aphrody).
   - npm / Bun workspaces: `bun-*` (Bun) vs `@aphrody/*` ([identity.ts](file:///C:/src/scripts/identity.ts)).
3. **Intact Upstream Fork Guarantee**:
   - `third_party/bun` remains a clean Git repository tracking `origin = aphrody-labs/bun` and `upstream = oven-sh/bun` via [stacks.toml](file:///C:/src/infra/upstream/stacks.toml), with zero Aphrody root files committed inside the fork.
