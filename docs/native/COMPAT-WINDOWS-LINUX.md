# Compatibilité Windows natif / Linux de src

Audit du 2026-11-13. But : chaque composant tourne en Windows natif (pas « réservé à WSL ») et sous Linux.
Priorité : UI natives desktop (GPUI, Microsoft WebUI, UI native Zig de Vercel, Material 3) et computer use.
Vérification : `cargo check` sur fr1 (`aphrody-heavy`), `x86_64-unknown-linux-gnu` et `x86_64-pc-windows-msvc`
(cargo-xwin), crates touchées seulement ; résultat en bas de page.

Hors périmètre de cet audit (traités par d'autres chantiers) : Chromium headless / agent-browser, agent-desktop.

## Corrigé dans ce chantier

| Composant                                                                        | Problème                                                 | Correction                                                                               |
| -------------------------------------------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| crates/depot-core (`just_engine`)                                                | `just.exe` cherché sous `C:\Users\aphro\...` codé en dur | `home_dir()` (`%USERPROFILE%` / `$HOME`) + `Path::join`, `just` sans `.exe` hors Windows |
| crates/depot-core (`vault`)                                                      | `.env` lu à `C:\src\.env`                                | `src_root()` (`$SRC_ROOT` ou ancêtre portant `src.lock.json`)                            |
| crates/depot-core (test gix)                                                     | racine `C:\src` dans un test                             | `CARGO_MANIFEST_DIR/../..`                                                               |
| crates/depot-cli (`maintainer`, `info`)                                          | racine par défaut `C:\src`                               | `depot_core::src_root()`, repli `.`                                                      |
| crates/rust-stack (`serve`, `auth`)                                              | base SQLite par défaut `C:\Users\aphro\.rust-stack\...`  | `default_db()` sous le home de la plateforme                                             |
| packages/env-kit (`cli.ts`, OAuth Google)                                        | `open` (macOS) appelé sous Linux                         | `xdg-open` sous Linux, `open` sous macOS, `cmd /c start` sous Windows                    |
| packages/ai-os (`brain/cli.ts`)                                                  | espace de confiance agy `C:\src`                         | racine dérivée de `import.meta.dir`                                                      |
| packages/google-design (`bun-docs-generator`, `themes-stylesheets`, `server.ts`) | chemins `C:\src\...`                                     | dérivés de `import.meta.dir` + `join`                                                    |
| packages/ffi-bridge (test)                                                       | DLL `.dll` et chemins `C:\Users\aphro`, `C:\src`         | `suffix` de `bun:ffi` (`.dll`/`.so`), `homedir()`, racine relative                       |
