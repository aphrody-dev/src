# unixwin : déduplication avec src (2026-11-13)

Pour chaque fonction couverte à la fois par unixwin et par src : qui fait autorité, ce qui est supprimé, et
pourquoi. Décisions validées avec la session shells (labs-1b) le 2026-11-13. Les appelants ont été cherchés avec
`rg` avant chaque suppression. Mesures : suite `apps/unixwin/tests` (123 tests), voir [LEARNINGS.md](LEARNINGS.md).

## Binaire niubash du poste

`tools.toml` (`niubash`) et `packages/machine/shells/shells.lock.toml` (`[shell.niubash]`) épinglent la
release amont v1.5.0 pour la première installation. Le binaire `niu.exe` en service vient de la chaîne de src
(forks aphrody-labs, [BUILD.md](BUILD.md)), installé par `just unixwin-install` ; son empreinte b3sum est celle
de `shells.lock.toml`.
