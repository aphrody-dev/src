## Gaps (ranked by impact on the game plan)

1. No single presentation API across Linux (`gamescope-cli`, winit 0.31 beta) and Windows (`dx12-hal`, DirectComposition). The game needs one, so the Bevy path (winit 0.30, wgpu 30) and the gamescope path do not conflict in one binary.
2. `wslg-cli` has no described body; its coverage is unknown.
3. `dx12-hal` describes a D3D12 and DirectComposition layer; no shader or frame-pacing module is described, so it cannot yet replace the Linux compositor path.
4. The Chromium WebGPU client (`gamescope-web-wasm`) and the Bevy wasm target (`src/game`, `webgpu` feature) both target WebGPU in the browser; there is no shared test that runs one frame in both.
5. No CDP client in Rust; `packages/chromium-bun` is TS only.
6. Benchmarks: the only report is historical (2026-11-10); no measured frame rate exists for the game on any platform.
