## Summary

- Present in repo: GPU stack (wgpu, D3D12 HAL, WGSL compute), audio and gamepad features, glTF feature, streamed terrain and synth in `src/game`, tv-* media, Lore VCS.
- Upstream, not wired: ray-traced lighting (`bevy_solari`), skeletal animation (`bevy_animation`), remote inspection (`bevy_remote`), physics crates, networking crates.
- Missing: Nanite-class geometry, a physics engine in the workspace, multiplayer netcode, an editor, a Verse-like scripting layer.
- Version conflict to settle before enabling `bevy_winit` in a shared binary: winit 0.30 (Bevy) vs 0.31 beta (repo). wgpu 30.0.1 pin is one patch behind 30.0.2.
