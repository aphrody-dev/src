# Merge of apps/aphrody and apps/aphrody-app (2026-11-13)

Target (PLAN.md section 6): one Aphrody app serving aphrody.com and aphrody.app, hosting the Craft Apps, ArtCraft and the game. This file maps every route and feature of the two apps to the merged app. Nothing is deleted by this step: each row stays in its source app until its replacement passes the check in the last column and `docs/games/PARITY.md` shows `done`.

Merged app layout (decision): `apps/aphrody` stays the web host (Bun server, build, Cloudflare edge worker); `/play` is the first mounted surface (already served, see below). The Rust shell of `apps/aphrody-app` becomes a shared crate set under `crates/` (see "Code moves"), so the merged app has one Bun host and no second workspace.

## Code moves (when the replacements pass)

1. `aphrody-core`, `aphrody-wasm`, `aphrody-android`, `aphrody-host` into `crates/` as workspace members (names already `aphrody-*`; check `ay arch check --strict` for the whitelist).
2. TypeScript of `apps/aphrody/src` that is not page-specific (store, benchmark, SEO documents, Google relay) into `packages/*` `@aphrody/*` packages.
3. Material tokens stay in `packages/design`; the shell and the game read the same tokens (`docs/design/DESIGN_SYSTEM.md`).

## Order

1. `/play` (done, this step): wasm game under `apps/aphrody`.
2. Hostname routing for `aphrody.app` in the web host, shell page served from the same dist.
3. One WebMCP registry, one `/mcp`.
4. Move the Rust crates, then retire `apps/aphrody-app` once every row is `kept` or moved and `PARITY.md` is `done`.
