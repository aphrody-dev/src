## Démarrage (hyperfine 2.0.0 -N, 20 runs, ce PC, 2026-11-13)

`-l -c exit` = invocation de Claude Code ; « nu » = `--norc --noprofile` (ou `--norc` en `-i`).

version d'env.sh : 1,03 s par `bash -c`) ; env.sh n'utilise plus que `case` et `%%`/`#*`.

Reproduire :

```sh

  "C:/Users/aphro/.local/share/brush-main/brush.exe -i -c exit"

```
