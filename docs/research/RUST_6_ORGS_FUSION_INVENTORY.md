## 1. The 6-Layer Sovereign Rust Fusion Architecture (Replacing Chromium & JS UI Frameworks)

Chromium (`libcef`, Blink C++, Skia C++, V8) imposes >120 MB binary overhead, multi-process IPC serialization bottlenecks, and C++ memory-safety liabilities. By fusing the 6 upstream Rust organizations with our local workspaces in `C:\src`, we achieve **two complementary, 100% Pure-Rust native rendering pipelines** sharing the exact same lower layers (`tokio` -> `wgpu`/`naga` -> `taffy` + `aphrody-design-tokens`):

1. **Path A — Web/HTML/CSS-Compatible Reactive DOM without Chromium (`Dioxus 0.8` + `Blitz` + `Stylo` + `Taffy` + `Parley` + `Vello` + `WGPU`)**:
   - `dioxus` (`rsx!`, `dioxus-core`, `dioxus-signals`, `subsecond` hot-patching, `manganis` asset linker) drives a zero-JS VirtualDOM directly into `dioxus-native` / `blitz-dom`.
   - `servo/html5ever` parses HTML/SVG markup; `servo/stylo` + `selectors` + `cssparser` (or `lightningcss` in `crates/aphrody-design-layout`) resolves the CSS3/CSS4 cascade in parallel across CPU cores.
   - `stylo_taffy` translates computed styles into `DioxusLabs/taffy` (`v0.15.0`) Flexbox, CSS Grid, Block, and Float layout trees, calling `linebender/parley` (`v0.12.0`) + `fontique` + `skrifa` + `harfrust` for inline rich-text shaping and line-breaking.
   - `blitz-paint` emits 2D vector draw commands through `DioxusLabs/anyrender` (`v0.14.0`) into `linebender/vello` (`v0.11.0` GPU compute shaders or `vello_cpu`/`vello_gpu` `v0.3` sparse strips) + `kurbo` (`v0.13.1`) + `peniko` (`v0.6.1`), executed on hardware via `gfx-rs/wgpu` (`v30.0.1`) and `naga` (`v30.0.1`).
