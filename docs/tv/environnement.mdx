## Variables utilisateur ajoutées

- `PKG_CONFIG=C:\Program Files\pkgconf-3.0.10\pkgconf.exe`
- `PKG_CONFIG_PATH=C:\Program Files\gstreamer\1.0\msvc_x86_64\lib\pkgconfig`
- `Path` : ajout de `NASM`, `pkgconf-3.0.10` et `gstreamer\1.0\msvc_x86_64\bin`

Vérification : `pkgconf --modversion gstreamer-1.0 gstreamer-video-1.0 gstreamer-webrtc-1.0 gstreamer-app-1.0` renvoie `1.28.8.1`.

Les nouveaux terminaux voient ces variables ; la session en cours de Claude Code garde l'ancien environnement.
