## Rust

Origine (nv) : projet personnel de Graydon Hoare (2006), sponsorisé par Mozilla (2009), compilateur initial en OCaml, auto-hébergé en Rust dès 2011, 1.0 le 15/05/2015, Rust Foundation en 2021.

Chaîne rustc (architecture décrite dans le rustc-dev-guide) :

| Étape            | Représentation                | Rôle                                                                          |
| ---------------- | ----------------------------- | ----------------------------------------------------------------------------- |
| Lexing/parsing   | tokens → AST (`rustc_parse`)  | macros, expansion, résolution de noms                                         |
| Lowering         | HIR (`rustc_hir`)             | désucrage, inférence et vérification de types (`rustc_hir_typeck`)            |
| THIR             | arbre typé                    | vérification des motifs, `unsafe` checking                                    |
| MIR              | graphe de flux                | borrow checker (NLL, Polonius en cours), const-eval (Miri), optimisations MIR |
| Monomorphisation | instances                     | collecte des génériques à générer                                             |
| Codegen          | `rustc_codegen_ssa` → LLVM IR | backend par défaut LLVM                                                       |

- Backends alternatifs : `rustc_codegen_cranelift` (compilation rapide en debug, composant rustup sur certaines cibles, nv pour Windows MSVC) ; `rustc_codegen_gcc` (libgccjit, vise cibles non LLVM). État 2026 : nv.
- gccrs : front-end Rust intégré à GCC (depuis GCC 14, nv) ; ne compile pas encore `core` complet ni ne fait de borrow checking complet : nv au 12/11/2026.
- Bootstrap : rustc N est compilé par rustc N-1 (stage0 → stage1 → stage2), via `x.py`.
- Éditions : 2015, 2018, 2021, 2024 (nv : édition suivante annoncée). Opt-in par crate, interopérables.
- ABI : ABI Rust instable ; ABI stable seulement via `extern "C"` et `#[repr(C)]`.
- `unsafe` : 5 super-pouvoirs (déréf. pointeur brut, appel `unsafe fn`, `static mut`, trait `unsafe`, accès union) ; depuis l'édition 2024 les blocs `extern` doivent être `unsafe extern` (nv).
- FFI C : `extern "C"`, `#[repr(C)]`, `bindgen` (C → Rust via libclang), `cbindgen` (Rust → en-têtes C), crate `cc` (compile du C dans `build.rs`), `pkg-config`/`vcpkg` crates pour localiser les bibliothèques.

## C

- Origine (nv) : Dennis Ritchie, Bell Labs, 1972 ; K&R 1978 ; ANSI C89, ISO C90, C99, C11, C17, C23.
- C11 : `_Atomic`, threads `<threads.h>`, `_Generic`, `_Static_assert`, modèle mémoire.
- C17 : corrections seulement.
- C23 (v : adoptée 2024) : `nullptr`, `constexpr`, `typeof`, `#embed`, `_BitInt`, `bool`/`true` mots-clés, attributs `[[...]]`, binaires `0b`, `auto` (nv pour le détail de la liste).
- C2y (v) : en cours, brouillon N3998 du 25/10/2026. Contenu (`defer` TS, `_Countof`, etc.) : nv.

## GCC

- Origine (nv) : Richard Stallman, GNU, première version 1987 ; fork EGCS (1997) refusionné en 1999 ; maintenu par le GCC Steering Committee (FSF).
- Architecture : front-ends (C, C++, Fortran, Ada, D, Go, Modula-2, COBOL, Rust/gccrs) → **GENERIC** → **GIMPLE** (SSA, passes tree-ssa, LTO) → **RTL** (allocation de registres, ordonnancement) → assembleur.
- Versions : 16.2 dernière (v) ; une majeure par an au printemps (16.1 le 30/04/2026, v).

## LLVM / Clang

- Origine (nv) : Chris Lattner et Vikram Adve, UIUC, 2000 ; Apple à partir de 2005 ; Clang annoncé en 2007 ; licence Apache 2.0 avec exception LLVM depuis 2019.
- LLVM IR : SSA typée, trois formes (mémoire, `.ll` texte, bitcode `.bc`).
- Passes : nouveau pass manager (`opt -passes=...`), pipelines O0-O3, ThinLTO/LTO ; backends SelectionDAG/GlobalISel → MIR machine → MC.
- Clang : front-end C/C++/ObjC, `clang-cl` compatible MSVC ; lld (ELF, COFF `lld-link`, Mach-O, wasm).
- Versions : 23.1.5 dernière (v) ; rythme majeur semestriel (nv).
- Lien Rust : rustc embarque son fork de LLVM ; version exacte du LLVM de rustc 1.99 : nv (`rustc -vV`).

## FFmpeg

- Origine (nv) : Fabrice Bellard, 2000 ; Michael Niedermayer mainteneur 2004-2015 ; fork Libav 2011 (abandonné depuis) ; licence LGPL 2.1+ (GPL si options `--enable-gpl`).
- Bibliothèques : libavutil (mémoire, frames, hwcontext), libavcodec (codecs, parseurs, bsf), libavformat (conteneurs, protocoles), libavfilter (graphes de filtres), libswscale (échelle, conversion pixel), libswresample (rééchantillonnage), libavdevice (captures).
- Clone local (voir ffmpeg-analyse.mdx) : n9.1-dev, ~2 M lignes C, ~390 k asm, 610 décodeurs, 273 encodeurs, 372 démuxeurs, 190 muxeurs, 597 filtres, 89 hwaccels, pas d'AV2.
- Contribution : patchs par ffmpeg-devel (liste) et forge code.ffmpeg.org (Forgejo, nv pour l'état exact 2026), revue publique, tests FATE obligatoires, gouvernance General Assembly / Technical Committee.
- Versions 2025-2026 (v) : 8.0 « Huffman », 8.1 « Hoare », 9.0 « Lei » (9.0.2 le 18/09/2026).
