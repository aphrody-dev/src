## 3. How Major Linux Distributions Build and Deploy Kernels in Real-Time

Every distribution translates upstream tarballs and Git commits into bootable system images using specialized toolchains and deployment strategies:

| Distribution | Source Manifest | Build Toolchain | Compiler / Flags | Packaging & Deploy Mechanism |
| :--- | :--- | :--- | :--- | :--- |
| **Arch Linux / CachyOS** | `https://gitlab.archlinux.org/archlinux/packaging/packages/linux.git (PKGBUILD)` | makepkg + pacman + ccache | GCC 14+ / Clang 19 with -march=x86-64-v3 or -v4, ThinLTO | pkg.tar.zst (Zstandard level 19) -> pacman -Syu -> mkinitcpio / dracut -> systemd-boot / GRUB UKI |
| **Debian / Ubuntu Enterprise** | `https://salsa.debian.org/kernel-team/linux.git (debian/rules)` | dpkg-buildpackage + debhelper + kernel-wedge | GCC with retpoline, KASLR, stack protector strong, strict CFI | linux-image-*.deb (compressed with xz / zstd) -> apt-get upgrade -> update-initramfs -u -> update-grub -> kexec live reboot |
| **Fedora / Red Hat Enterprise Linux (RHEL)** | `https://src.fedoraproject.org/rpms/kernel.git (kernel.spec)` | rpmbuild + mock + Koji / Brew build system | GCC with Red Hat hardened spec flags (LTO, -fstack-clash-protection) | kernel-*.rpm (cpio + zstd) -> dnf upgrade -> dracut -> grubby / BLS -> kpatch live kernel patching without reboot |
| **NixOS (Declarative Linux)** | `https://github.com/NixOS/nixpkgs/tree/master/pkgs/os-specific/linux/kernel` | Nix hermetic sandbox builder (buildLinux / stdenv) | Clang or GCC pinned in nixpkgs stdenv | /nix/store/<hash>-linux-<version>/bzImage + modules -> nixos-rebuild switch -> atomic system profile generation symlink update |
| **Alpine Linux (Musl Minimal)** | `https://git.alpinelinux.org/aports/tree/main/linux-lts/APKBUILD` | abuild + apk-tools | Alpine GCC targeting musl libc ABI | linux-lts-*.apk (tar + gzip/zstd signature verified) -> apk add --upgrade linux-lts -> update-extlinux -> sub-50ms reboot |
| **Android / AOSP (Generic Kernel Image - GKI)** | `https://android.googlesource.com/kernel/common (build.config)` | Bazel / Kleaf build harness + Android NDK Clang | Google Prebuilt Android LLVM/Clang with ThinLTO and Kernel Control Flow Integrity (kCFI) | boot.img / vendor_boot.img (Android sparse image) -> Fastboot flash / Dynamic Partitions OTA -> A/B seamless partition slot swap |


### 3.1 Real-Time Kernel Deployment Models:
1. **Traditional Monolithic Bootloader Update** (Debian, Arch): The package manager writes `vmlinuz` and calls `mkinitcpio` or `dracut` to generate an initramfs, updating `grub.cfg` or `systemd-boot` loader entries.
2. **Atomic Generation Symlink Swap** (NixOS, Guix): The build outputs a complete hermetic derivation in `/nix/store`. Activating the new kernel updates the system generation symlink, providing instant rollback without file collision.
3. **A/B Seamless Partition Flipping** (Android AOSP): The update engine flashes the inactive partition slot (`boot_b`). Upon verification, the bootloader flag is toggled to boot into slot B on the next restart.
4. **Zero-Reboot Live Patching** (Enterprise RHEL / SUSE): Tools like **kpatch** and **kGraft** inject binary diffs directly into the running kernel memory using `ftrace` redirection, patching high-severity vulnerabilities without taking servers offline.
