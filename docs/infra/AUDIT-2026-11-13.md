## Fixes

- apps/shenron `apps/site/src/components/home/SagaBestOf.tsx`: `role="tabpanel"` was set on an `<article>`, a role ARIA in HTML does not allow on that element, which broke the accessibility tree for agents. Changed to `<div>` (same classes, `aria-labelledby`, `tabIndex`). Committed and pushed in the shenron submodule (dbb9107f). The superproject pointer is not bumped here because `apps/shenron` carries other uncommitted edits.
- No change to the other apps: nothing failed.
- Not done in this pass: dev server with `bun --hot`, Next-compatible prod server, nginx/Dockerfile tuning. The audited sites showed no failing audit that these would address, and nothing compiles on the workstation. Candidates should come from a measured Performance trace.
