- fr1 `~/src-flat`, `~/srcw`, fr2 `~/src/{rosegriffon,shenron,yolo-jobs,yolo-work}`: written within the last hour by running agents; revisit when idle.
- fr1 Docker build cache (19 GB, 13 GB reclaimable): the shared buildx cache of the self-hosted image builds; `--filter until=24h` matched nothing.
- prd Docker images (13 GB reclaimable): all younger than 48 h, possible rollback targets.
- fr2 distro `gcc` and `clang` packages stay (shared dependencies of other packages); only the Rust toolchain was removed.
- `wii-os-shenron` (prd, LEGACY in `docs/infra/PROD-MAP.md`) and the Cloudflare DNS and Worker records of `var/agents/outbox/decommission.md`: no verified replacement or no DNS token; stay held.
