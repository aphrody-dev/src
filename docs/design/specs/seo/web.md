# Référencement technique (SEO)

Spec `web.seo` · domaine `seo` · sources lues le 2026-11-13 · JSON : [`web.json`](./web.json) (schéma `../spec.schema.json`).

Exigences de découvrabilité pour les pages publiques de src, alignées sur la catégorie SEO de Lighthouse 13 et ses pages d'audit sur developer.chrome.com. Le contenu éditorial et les consignes propres à chaque moteur restent hors de cette spec.

Synthèse normative réécrite ; aucun passage recopié. Textes sources sous CC BY 4.0 (code Apache 2.0), © Google LLC et auteurs cités, sauf WCAG 2.2 (W3C Document License, cité par numéro).

Niveaux : MUST, MUST-NOT, SHOULD, SHOULD-NOT, MAY au sens de la RFC 2119.

## Règles

| id                             | niveau   | règle                                                                                                                                                                                                                                                                           | valeur                                       | source                                                                      |
| ------------------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- | --------------------------------------------------------------------------- |
| `web.seo.lighthouse-gate`      | MUST     | Chaque page publique passe la catégorie SEO de Lighthouse en CI sans échec ; tous les audits automatiques pèsent le même poids, l'audit données structurées est manuel et hors score.                                                                                           |                                              | [lien](https://developer.chrome.com/docs/lighthouse/seo/hreflang)           |
| `web.seo.http-status`          | MUST     | Les pages à indexer répondent en 2xx ; pages d'erreur et 404 servies avec leur vrai code 4xx/5xx et exclues de l'index.                                                                                                                                                         |                                              | [lien](https://developer.chrome.com/docs/lighthouse/seo/http-status-code)   |
| `web.seo.title`                | MUST     | Un title unique et descriptif par page et par route de SPA.                                                                                                                                                                                                                     |                                              | [lien](https://web.dev/learn/accessibility/javascript)                      |
| `web.seo.meta-description`     | MUST     | Un <meta name="description"> non vide, unique et propre à la page dans le head ; Lighthouse ne vérifie que la présence, la qualité reste à notre charge.                                                                                                                        |                                              | [lien](https://developer.chrome.com/docs/lighthouse/seo/meta-description)   |
| `web.seo.canonical`            | MUST     | Au plus un lien canonical, URL absolue valide, même domaine, même langue et région, et pas la racine du site pour une page profonde.                                                                                                                                            | `{"max_canonical_links":1}`                  | [lien](https://developer.chrome.com/docs/lighthouse/seo/canonical)          |
| `web.seo.indexable`            | MUST     | Aucun noindex (meta robots ou en-tête X-Robots-Tag) sur une page destinée à l'index ; noindex seulement pour les contenus volontairement exclus.                                                                                                                                |                                              | [lien](https://developer.chrome.com/docs/lighthouse/seo/is-crawlable)       |
| `web.seo.robots-txt`           | MUST     | robots.txt valide (user-agent déclaré, motifs vides ou commençant par / ou *, directives connues), servi sans 5xx, inférieur à 500 KiB ; il s'applique à tout l'hôte.                                                                                                           | `{"max_kib":500}`                            | [lien](https://developer.chrome.com/docs/lighthouse/seo/invalid-robots-txt) |
| `web.seo.sitemap`              | MUST     | Publier un sitemap et le déclarer dans robots.txt par une URL absolue.                                                                                                                                                                                                          |                                              | [lien](https://developer.chrome.com/docs/lighthouse/seo/invalid-robots-txt) |
| `web.seo.hreflang`             | MUST     | Pour chaque variante linguistique, déclarer toutes les versions via link rel=alternate hreflang (head, en-tête HTTP ou sitemap) avec des codes de langue valides, URL absolues, et x-default pour le sélecteur de langue ; Lighthouse ne contrôle ni les régions ni le sitemap. |                                              | [lien](https://developer.chrome.com/docs/lighthouse/seo/hreflang)           |
| `web.seo.link-text`            | MUST     | Texte de lien descriptif de la cible ; Lighthouse refuse les libellés génériques (click here, click this, go, here, this, start, right here, more, learn more) et leurs équivalents français sont proscrits chez nous.                                                          |                                              | [lien](https://developer.chrome.com/docs/lighthouse/seo/link-text)          |
| `web.seo.crawlable-links`      | MUST     | Règle maison, sans page source : la page d’audit Lighthouse crawlable-anchors répond 404 sur developer.chrome.com le 2026-11-13. La navigation passe par de vrais éléments <a href> vers des URL résolubles, jamais par du JavaScript seul sur des éléments non liens.          |                                              | règle maison                                                                |
| `web.seo.structured-data`      | SHOULD   | Baliser le type de contenu (article, produit, FAQ…) en données structurées selon la référence du moteur, sur chaque page concernée, puis valider ; audit manuel.                                                                                                                |                                              | [lien](https://developer.chrome.com/docs/lighthouse/seo/structured-data)    |
| `web.seo.no-plugins`           | MUST-NOT | Pas de contenu dépendant de plugins (embed, object, applet avec types Java, Flash…) : il n'est pas indexé.                                                                                                                                                                      |                                              | [lien](https://developer.chrome.com/docs/lighthouse/seo/plugins)            |
| `web.seo.tap-targets`          | SHOULD   | Cibles tactiles d'au moins 48 × 48 px sans chevauchement de plus de 25 % dans un rayon de 48 px ; le minimum normatif d'accessibilité reste 24 px (web.a11y.target-size).                                                                                                       | `{"min_px":48,"max_overlap":0.25}`           | [lien](https://developer.chrome.com/docs/lighthouse/seo/tap-targets)        |
| `web.seo.font-size-legibility` | SHOULD   | Garder le texte de lecture à 12 px ou plus sur mobile pour la lisibilité ; l'audit font-size a été retiré de Lighthouse 13, ce n'est plus un signal SEO.                                                                                                                        | `{"min_px":12,"lighthouse":"retiré en v13"}` | [lien](https://developer.chrome.com/blog/lighthouse-13-0)                   |
| `web.seo.beyond-lighthouse`    | SHOULD   | Lighthouse ne couvre pas tout le référencement : vérifier aussi les consignes de chaque moteur visé (Google Search, Bing, Yandex) et tenir les Core Web Vitals de perf.core-web-vitals.                                                                                         |                                              | [lien](https://web.dev/articles/pass-lighthouse-seo-audit)                  |

## Conflits et réserves relevés

- L'audit font-size (texte < 12 px sur ≥ 40 % de la page) est retiré de Lighthouse 13 ; sa page DCC reste en ligne avec un avertissement. Conservé en SHOULD pour la lisibilité uniquement.
- Aucune page d'audit crawlable-anchors, document-title ni d'index des audits SEO n'existe sur developer.chrome.com (404 le 2026-11-13) : web.seo.crawlable-links est une règle maison sans source, web.seo.title s'appuie sur la page JavaScript de web.dev/learn/accessibility.
- tap-targets (48 px) contre WCAG 2.5.8 (24 px) : voir a11y/web.
