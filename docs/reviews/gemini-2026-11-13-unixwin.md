# Revue Gemini (Carbon High) : intégration unixwin

Relais `gemini_review` (moteur antigravity), 2026-11-13. Objet : correctif glob Windows du fork
`aphrody-labs/rubash` (`ae43f3e5`), installation de `niu.exe` (`scripts/unixwin/unixwin.ts install`), build prd
(`infra/unixwin/prd-build.sh`). Note : 11/20 (glob 4/8, installation 4/7, build 3/5). La revue porte sur des extraits
et non sur le dépôt.
