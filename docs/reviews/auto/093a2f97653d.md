## Bloquants

1. **Les fonds d'écran 4K, QHD et mobile ne sont pas dans le commit.**
   - Seules les miniatures sont versionnées. Les originaux vont dans `var/wallpapers`, ignoré par `.gitignore:20`.
   - Le message de commit les annonce pourtant.
   - `validate` (`gen.ts:695-729`) lit ce répertoire, donc il échoue sur 420 fichiers "missing" dans un clone propre.
   - Correction : committer les originaux, ou renommer le commit et faire valider `validate` uniquement ce qui est versionné.
2. **`manifest.toml` pointe vers 420 URLs non vérifiées.**
   - Ce sont les entrées `storage = "remote"` sur `cdn.aphrody.com`, sans étape d'upload dans le code (`gen.ts:73`, `687-688`).
   - Ajouter un `HEAD` + comparaison de sha256 dans `validate`.
3. **Les PNG de marque n'ont pas de glyphe.**
   - `sdfIcon` (`gen.ts:291-329`) n'appelle jamais `GLYPHS`.
   - `favicon-32.png`, `apple-touch-icon-180.png` et `tile-512.webp` sont des dégradés flous sans symbole. J'ai ouvert `apple-touch-icon-180.png` : aucun glyphe.
   - Les coins sont blancs et opaques (`lerp(255, …, a)`, `gen.ts:322`), alors que le writer PNG est RGB sans alpha (`core.ts:251`).
   - Pour l'apple-touch, il faut un carré plein sans arrondi.
4. **L'image OG n'a ni glyphe ni texte.**
   - Le commentaire `gen.ts:343` parle d'une marque géométrique, mais le code dessine un simple disque translucide (`gen.ts:347-353`).
   - En mode sombre, il est éclairci vers 20 donc quasi invisible (`p.dark ? 20 : 255`).
   - `og:image` en WebP n'est pas accepté de façon fiable par tous les crawlers. C'est un risque que je n'ai pas testé.

## Majeurs

5. **Le contrôle de contraste est tautologique.**
   - `legibilize` (`styles.ts:392`, ratio 4.6) écrête la zone de texte juste avant `minContrast` (`gen.ts:166-180`), qui mesure donc le propre écrêtage.
   - La galerie confirme : 35 des 70 fonds affichent exactement 4.6:1.
   - La marge est de 0.1 seulement et la mesure se fait avant dither, WebP q80 et AVIF yuv420p10 (`gen.ts:147`).
   - L'échantillonnage tous les 5 px (`gen.ts:170`) peut rater les étoiles.
   - Correction : décoder le fichier final et mesurer dessus, avec ratio visé ≥ 4.8.
6. **Le contraste du favicon dark est insuffisant.**
   - Dans `favicon-dark.svg`, le dégradé va de `#3861E5` à `#D1BDF5` avec un glyphe `#fff`. Le contraste en bas à droite est d'environ 1.7:1, sous le seuil de 3:1 (WCAG 1.4.11).
   - Dans `favicon-light.svg`, les deux stops sont quasi identiques (`#1242FF` et `#1D48FF`), donc le dégradé est dégénéré (`svg.ts:260-261`).
7. **Les animations SMIL ignorent `prefers-reduced-motion`.**
   - C'est le cas de `mesh-smil`, `waves` (`svg.ts:62`), des spinners (`svg.ts:228-245`) et de `loading-*`.
   - Seuls les variantes CSS (`svg.ts:31`, `73`) le respectent.
   - Les `<animate>` ne peuvent pas être neutralisés en CSS : il faut servir une variante statique.
8. **Les SVG de fond n'ont aucune garantie de lisibilité.** Le passe `legibilize` n'existe que pour le raster. `svgLoading` pose `p.ink` sur un mesh aléatoire sans contrôle.
9. **Les ids SVG sont fixes (`b`, `g`, `n`).** Ils entrent en collision dès que deux SVG sont inlinés dans la même page (`svg.ts:29`, `50`, `74`, `263`).
10. **Le flou animé est coûteux.** `feGaussianBlur stdDeviation=110` est appliqué à un groupe de 6 cercles animés en 1920×1080 (`svg.ts:29`, `32`). Il est re-rastérisé à chaque frame. Les fichiers `*-stars.svg` pèsent 32 Ko avec 260 cercles animés par CSS (`svg.ts:77`).
11. **Les fichiers générés ne sont pas tous cohérents avec le manifeste.**
    - `nohup.out` (7 lignes, erreur `favicon.ico` ENOENT) est committé, absent du manifeste, et `gallery.html` y apparaît avec `kind = "gallery.html"` (`gen.ts:681`, `kind = f.split("/")[0]`).
    - Le chemin de génération du manifeste exclut `manifest.toml` et `wallpapers.json` mais pas ces artefacts parasites.
    - Supprimer `nohup.out`, ajouter une liste d'exclusion, et générer `favicon.ico` (la raison du 404).
12. **Les licences sont contradictoires.**
    - `wallpapers.json` dit `MIT OR Apache-2.0` (`gen.ts:654`).
    - Chaque entrée du manifeste dit `Apache-2.0` (`gen.ts:675`) et l'en-tête (`gen.ts:666`) mélange les deux.
    - Choisir une seule valeur ou une expression SPDX valide partout.
13. **Les URLs du manifeste sont mutables.** Elles pointent vers `…/src/main/assets/…` (`gen.ts:683`) tandis que le sha256 est figé. Utiliser le SHA du commit ou un chemin CDN versionné.

## Moyens

- **Jobs parallèles :** `gen.ts:198` attend `p.exited` mais ignore les codes de sortie. Un shard qui plante n'est pas signalé et `process.exitCode` reste 0.
- **Fichiers temporaires :** `tmpf` (`gen.ts:124-154`) écrit un PNG 4K à chaque image sans jamais supprimer `in.png` ni `out.avif`.
- **AVIF :**
  - La couleur n'est pas taguée (matrice BT.601 par défaut côté ffmpeg lors de la conversion RGB vers YUV). À vérifier avec `ffprobe`.
  - Le sous-échantillonnage 4:2:0 dégrade les traits fins de `topo` et `stars`. Utiliser `yuv444p10le` et `-colorspace bt709`.
- **PNG :**
  - Le writer (`core.ts:227-262`) utilise le niveau 1 et le filtre 0 uniquement.
  - Combiné au dither, ça donne 58 Ko pour un 180×180.
  - Utiliser `Bun.Image` pour encoder le PNG final, ou activer les filtres et le niveau 9.
- **Commentaire faux :** `core.ts:194` parle de dither « blue-ish », mais `h2(x,y)+h2(x+7919,…)-1` est un bruit blanc triangulaire.
- **Pas de téléchargement de la pile vidéo vérifiée :** `video()` n'est pas dans `all` (`gen.ts:763-771`), alors que `index()` indexe des vidéos. Le commit ne contient aucune vidéo.
- **GIF :** seulement des `mesh` en mode sombre, 2 s, 96 couleurs avec dither Bayer, donc banding visible. Aucun GIF clair.
- **Galerie :**
  - `gallery.html` est une ligne de 30 Ko.
  - Les mobiles sont uniquement en sombre (`gen.ts:809`).
  - Les patterns sont uniquement `ember-dark` (`gen.ts:841`).
  - Les SVG sont uniquement `aphrody` (`gen.ts:821`).
  - La CLI et le message d'usage (`gen.ts:776`) n'indiquent pas `gallery`.
- **Dispatch confus :** `gen.ts:761` est un `if` vide. `table.gallery` est assigné en `gen.ts:870`, après la fin du dispatch. Déplacer la fonction avant et supprimer la branche vide.
