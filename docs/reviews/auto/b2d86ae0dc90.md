Si les noms de fichiers ne sont pas hachés, un fichier republié reste périmé pendant un an sur le CDN. Il faut vérifier que les noms contiennent un hash de contenu, sinon baisser le `maxAge`.

Si le code lit `t.public_url` (à vérifier avec `rg public_url packages/assets`), il peut se retrouver `undefined` et produire des URL invalides. Il faut ajouter une validation ou une valeur par défaut explicite. L'ancienne valeur par défaut (`blob.vercel-storage.com`) était déjà fausse, mais la remplacer par rien est une régression silencieuse.
