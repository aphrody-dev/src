**Défauts**

1. **`deny.toml` (l. 2638-2639), régression de sécurité.** Autoriser l'organisation entière `storytold` élargit la politique « forks only » à tous ses dépôts, alors que le commentaire dit qu'un seul est consommé. Correction : utiliser une liste de dépôts autorisés (`allow-git`) limitée à `https://github.com/storytold/craft-libs`.

2. **`crates/craft-formats/Cargo.toml` (l. 2375-2382), dépendance non vérifiée.** Six crates git sont pinnées sur un `rev` d'un dépôt tiers non forké. C'est contraire à la politique « forks only » de `deny.toml` (« forks only : aphrody-labs, aphrody-dev »). Correction : forker `craft-libs` dans `aphrody-labs`, puis pinner le fork. Autre option : documenter explicitement l'exception dans `deny.toml`, comme c'est fait pour ffmpeg-next.

3. **`crates/craft-formats/Cargo.toml` (l. 2377-2382), duplication du `rev`.** Le `rev` est répété six fois. Correction : le déclarer une seule fois dans `[workspace.dependencies]` et utiliser `workspace = true`.

4. **`crates/craft-formats/Cargo.toml` (l. 2364), description inexacte.** La description annonce une lecture des en-têtes de SVG, WebP, EXR, PSD, TIFF et HEIF, mais SVG et TIFF ne renvoient aucune taille. Correction : aligner la description sur le comportement réel, ou extraire largeur et hauteur pour ces deux formats.

5. **`crates/craft-formats/src/lib.rs`, `detect` (l. 2442), HEIF incomplet.** Les marques `avif`, `heim`, `heis`, `hevx` et `mif2` ne sont pas reconnues. Correction : lire les marques compatibles de la boîte `ftyp` au lieu de n'examiner que la marque principale.

6. **`crates/craft-formats/src/lib.rs`, `detect` (l. 2434-2449), ordre de détection.** L'ordre est ad hoc. Le test `is_svg` appliqué sur des octets arbitraires peut produire de faux positifs ou négatifs. L'EXR est détecté sur 4 octets seulement. Correction : tester l'en-tête complet avant l'heuristique SVG, et ajouter des tests de non-régression avec du contenu texte qui ressemble à du SVG.

7. **`crates/craft-formats/src/lib.rs`, `probe` Psd (l. 2468), `count` figé à 1.** Pour un PSD, `count` devrait être le nombre de calques si l'on suit la doc de `Info` (« Parts ou IFDs »). Pour les formats multi-images (HEIF), 1 est aussi codé en dur. Correction : lire le nombre d'items dans `craft_heif`, ou documenter que `count` n'est pas fiable pour ces formats.

8. **`crates/craft-formats/src/lib.rs`, `probe` (l. 2454), `Error::Malformed` stocke une `String`.** Le message mélange `to_string()` et `{e:?}` (HEIF), donc les formats d'erreur sont incohérents. Correction : conserver une source typée (`Box<dyn Error>`) et implémenter `source()`.

9. **`crates/craft-formats/src/lib.rs` (l. 2481-2483), `window_size` inutile.** Cette fonction n'est utilisée qu'une fois. Elle peut aussi être fausse : `Window.width` est peut-être un `u32` calculé depuis `max - min + 1`, ce que je n'ai pas pu vérifier. Correction : vérifier le type et le calcul dans `craft-libs`, et inliner la fonction.

10. **`crates/craft-formats/src/lib.rs`, tests (l. 2485-2530), couverture insuffisante.** Il n'y a pas de test positif pour EXR, PSD ni HEIF, seulement un test d'échec PSD tronqué. Aucun test ne vérifie la taille pour TIFF. Il n'y a pas de test d'entrée vide ni de limite de `scan(bytes, 4096)`. Correction : ajouter des fixtures minimales pour EXR, PSD et HEIF, et des tests sur entrée vide.

11. **`crates/aphrody-ui/tests/bevy_headless.rs` (l. 2336-2353), test peu discriminant.** Le test vérifie seulement qu'un `Node` survit à `app.update()` avec `MinimalPlugins`, ce qui est trivial. Il ne teste pas la conversion CSS dans le monde ECS. Correction : ajouter un cas avec `TokenTable` non vide et un cas d'erreur CSS.

12. **`crates/aphrody-ui/Cargo.toml` (l. 2311-2323), features Bevy excessives.** `bevy_gltf`, `bevy_audio`, `bevy_pbr` et `bevy_winit` sont activées pour un crate qui ne fait que convertir du CSS en `Node`. Le diff de `Cargo.lock` le confirme : `cpal`, `alsa`, `rodio` et `bevy_audio` y entrent. Cela alourdit la compilation et ajoute des dépendances système (ALSA). Correction : ne garder que `bevy_ui` (et ce que le test exige), et déplacer le reste dans une feature `bevy-full`.

13. **`crates/aphrody-ui/Cargo.toml` (l. 2293), feature `bevy` couplée à `layout`.** `bevy = ["dep:bevy", "layout"]` impose lightningcss à tout consommateur de la feature `bevy`. À justifier, ou à rendre optionnel.

14. **`crates/aphrody-ui/Cargo.toml` et `deny.toml`, reformatage massif sans rapport.** La mise sur plusieurs lignes de `react`, `brand`, `taffy` et `allow` noie les vrais changements. Correction : isoler le formatage dans un commit séparé.

15. **`Cargo.toml` (l. 2256-2257), régression de version.** Le passage de `winit` 0.31.0-beta.4 à 0.30.13 est une régression. Elle contredit la politique « toujours la dernière version, y compris canary et pré-release ». Elle est justifiée par `bevy_winit` 0.20.1 et `egui-winit` 0.37.0, mais je n'ai pas pu confirmer ces dépendances. Correction : confirmer avec `cargo tree -i winit`. Documenter aussi la dérogation, avec une condition de retour à 0.31.

16. **`crates/gamescope-cli/src/main.rs` (l. 2535-2597), retour en arrière de l'API sans test.** Le crate repasse de l'API `Window` en trait objet (0.31) à celle de 0.30, sans test compilé ni cas de redimensionnement. Deux points sont à corriger :
    - `resumed` est appelé à chaque reprise (Android), donc le `if self.window.is_some()` doit aussi couvrir `device`, `surface` et `queue`.
    - `Arc::new(event_loop.create_window(..))` : sous winit 0.30, `create_window` est dépréciée au profit de `create_window` dans `resumed`, donc à vérifier.

17. **`Cargo.lock` (l. 3834-3854), doublons de dépendances.** `calloop` revient en 0.13.0 (au lieu de 0.14.5), `rustix 0.38.44` s'ajoute à `rustix 1.1.6`, et `objc2` existe en deux versions (0.5.3 et 0.6.5). `bevy_winit` entraîne aussi `accesskit_*`. Correction : lancer `cargo deny check bans` et `cargo tree -d`, et définir une politique `multiple-versions`.

18. **`Cargo.lock` (l. 4474-4560), nouveau coût de compilation.** Le diff de `Cargo.lock` fait plus de 1400 lignes pour un crate d'en-têtes, avec `heic-rs`, `rayon`, `exr`, `encoding_rs`, `flate2` et `quick-xml`. Correction : mesurer, et mettre HEIF et EXR derrière des features Cargo pour que `craft-formats` reste léger.

19. **Absence de CI et de preuve.** Le message de commit n'indique ni `cargo deny check`, ni `cargo test -p craft-formats`, ni `cargo test -p aphrody-ui --features bevy`. Le commit mélange cinq changements sans rapport : formats d'image, winit, features Bevy, test headless et licences. Correction : le découper en commits atomiques, un par sujet.
