# Aphrody (`apps/aphrody`)

Merged static SEO and brand assets distribution for `aphrody.com` and `aphrody.app`.
All application source code, servers, bundlers, and workers have been purged; UI design tokens live in `packages/design` and native runtimes in `crates/*`.

## Contents

- `public/` — static zero-JS semantic HTML (`fr`, `en`, `es`, `ja`, `zh-CN`, `404.html`), `robots.txt`, `sitemap*.xml`, `llms*.txt`, `ads.txt`, `sellers.json`, `humans.txt`, `.well-known/{security.txt,agent.json,webmcp.json}`, `_headers`, `tokens.css`, icons, fonts, OG images, and screenshots (`shots/`).
- `assets/wayland/aphrody.desktop` — Wayland desktop entry.
